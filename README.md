# ローカル匿名化ツール

個人情報などを含む文章から、選択した文字列を `[PERSON_1]` などのラベルに置き換える単一HTMLアプリです。

## 設計方針

- スマートフォン、とくにiPhone Safariで操作しやすいレイアウトと44px以上のタップ領域を採用
- 外部ライブラリー・ビルド工程に依存しない単一HTML構成
- Content Security Policyで外部通信・外部リソース読み込みを制限
- 入力文・候補・置換対応表をWeb Storage等に保存しない
- 自動検出は補助とし、利用者が候補を確認してから置換する
- 検出の検証には架空データを使う

## 使い方

1. `index.html` をHTTPSのWebホスティング先で開く
2. 「サンプルを入力」で架空データを試す
3. 「候補を検出」を押し、伏せる候補を確認する
4. 「選択した候補を置換」で結果を作る
5. 作業後は「すべてクリア」を押す

## プライバシー上の注意

- 自動検出は完全ではなく、見逃し・誤検出があります。必ず候補と出力を確認してください。
- パスワード、認証コード、秘密鍵、会社の機密情報は入力しないでください。所属組織のルールを優先してください。
- このリポジトリは非公開のままです。コードを保存することと、Webアプリを公開することは別です。
- GitHub Pages等で配信する場合は、サイトの公開範囲を確認してから設定してください。
- CSPはブラウザー内での処理を補助する防御策ですが、端末管理ソフト、拡張機能、スクリーンショット、OS側の記録等まで防止するものではありません。
- iPhone実機での確認は未完了です。まず架空データだけで動作確認してください。
